# Isolation

A 7×7 knight strategy game. Move to an empty square and burn the square you left. The first player who cannot move loses.

[Play on GitHub Pages](https://andreaisabelmontana.github.io/isolation-game/) · [Portfolio projects](https://andreamontana.com/online/)

Play against three computer levels. Strategic mode uses four-ply alpha-beta search and breadth-first knight-move distances to evaluate territory. Open **How it works** for small examples of the move, burn, and search logic.

Open `index.html` in a browser to run locally, or run `node tests.cjs` (Node 18+) for the offline regression tests. No server, credentials, or build step.
